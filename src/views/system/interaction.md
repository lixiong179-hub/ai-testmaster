## 2. 用户管理流程

### 访问用户管理页面
1. **登录系统**：使用管理员账号登录
2. **进入系统管理**：在左侧菜单点击"系统管理" → "用户管理"
3. **验证权限**：如果没有`user:list`权限，将被重定向到仪表盘

### 新增用户
1. **点击新增按钮**：点击页面右上角"新增用户"按钮
2. **填写表单**：
   - 用户名：`testuser`
   - 邮箱：`test@example.com`
   - 手机号：`13800138001`
   - 密码：`password123`
   - 状态：开启
3. **点击保存**：点击"保存"按钮
4. **验证结果**：
   - 成功：显示"用户创建成功"提示，列表中出现新用户
   - 失败：显示具体错误信息（如"用户名已存在"）

### 编辑用户
1. **选择用户**：在用户列表中找到要编辑的用户
2. **点击编辑**：点击"编辑"按钮
3. **修改信息**：修改邮箱或手机号等信息
4. **点击保存**：点击"保存"按钮
5. **验证结果**：显示"用户更新成功"提示

### 禁用/启用用户
1. **选择用户**：在用户列表中找到要操作的用户
2. **点击禁用/启用**：点击"禁用"或"启用"按钮
3. **确认操作**：在弹出的确认对话框中点击"确定"
4. **验证结果**：
   - 禁用：用户状态变为"禁用"，按钮变为"启用"
   - 启用：用户状态变为"启用"，按钮变为"禁用"

### 分配角色
1. **选择用户**：在用户列表中找到要分配角色的用户
2. **点击分配角色**：点击"分配角色"按钮
3. **选择角色**：在弹出的对话框中选择一个或多个角色
4. **点击保存**：点击"保存"按钮
5. **验证结果**：显示"角色分配成功"提示

## 3. 角色管理流程

### 访问角色管理页面
1. **登录系统**：使用管理员账号登录
2. **进入系统管理**：在左侧菜单点击"系统管理" → "角色管理"
3. **验证权限**：如果没有`role:list`权限，将被重定向到仪表盘

### 新增角色
1. **点击新增按钮**：点击页面右上角"新增角色"按钮
2. **填写表单**：
   - 角色名称：`manager`
   - 角色描述：`管理角色`
3. **点击保存**：点击"保存"按钮
4. **验证结果**：显示"角色创建成功"提示

### 编辑角色
1. **选择角色**：在角色列表中找到要编辑的角色
2. **点击编辑**：点击"编辑"按钮
3. **修改信息**：修改角色描述等信息
4. **点击保存**：点击"保存"按钮
5. **验证结果**：显示"角色更新成功"提示

### 分配权限
1. **选择角色**：在角色列表中找到要分配权限的角色
2. **点击分配权限**：点击"分配权限"按钮
3. **选择权限**：在树形选择器中选择权限
4. **点击保存**：点击"保存"按钮
5. **验证结果**：显示"权限分配成功"提示

### 删除角色
1. **选择角色**：在角色列表中找到要删除的角色
2. **点击删除**：点击"删除"按钮
3. **确认操作**：在弹出的确认对话框中点击"确定"
4. **验证结果**：显示"角色删除成功"提示

## 4. 个人中心流程

### 访问个人中心
1. **登录系统**：使用任意账号登录
2. **进入个人中心**：在左侧菜单点击"个人中心"

### 修改密码
1. **切换到修改密码**：点击"修改密码"选项卡
2. **填写表单**：
   - 当前密码：`password123`
   - 新密码：`newpassword123`
   - 确认密码：`newpassword123`
3. **点击确认修改**：点击"确认修改"按钮
4. **验证结果**：显示"密码修改成功，请重新登录"提示

### 查看登录日志
1. **切换到登录日志**：点击"登录日志"选项卡
2. **筛选日志**：选择日期范围，点击"搜索"按钮
3. **验证结果**：显示符合条件的登录日志列表

## 5. 权限验证

### 路由级权限
1. **使用无权限账号登录**：使用没有系统管理权限的账号登录
2. **尝试访问系统管理**：在地址栏输入 `http://localhost:8080/home/system/user`
3. **验证结果**：自动重定向到仪表盘页面

### 按钮级权限
1. **使用有限权限账号登录**：使用只有查看权限的账号登录
2. **访问用户管理**：进入用户管理页面
3. **验证结果**：
   - 看不到"新增用户"按钮
   - 看不到"编辑"、"禁用"、"分配角色"按钮

## 6. 移动端适配

### 测试移动端界面
1. **打开浏览器开发者工具**：按 F12 打开开发者工具
2. **切换到移动设备模式**：点击设备切换按钮
3. **选择移动设备**：选择 iPhone 或 Android 设备
4. **访问各页面**：
   - 登录页面：表单自适应，输入框变大
   - 用户管理：表格内容自动调整，操作按钮换行
   - 角色管理：树形选择器适应屏幕宽度
5. **验证操作**：测试所有功能在移动端的可用性
