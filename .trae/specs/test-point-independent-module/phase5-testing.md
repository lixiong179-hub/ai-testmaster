# Phase 5: 测试与回归验证（4个任务）

---

## T5.1: 功能测试（完整功能验证）

| 属性 | 内容 |
|------|------|
| **优先级** | 🔴 高 |
| **负责人** | 全栈开发/测试 |
| **预计工时** | 1.5 小时 |
| **依赖关系** | T4.1-T4.2 |
| **时间节点** | Phase5 第1个任务 |

---

### 目标描述

完整验证所有新功能是否正常工作，确保没有功能性bug。

---

### 具体测试场景

1. **测试点CRUD测试**
   - 新增测试点（必填/非必填字段）
   - 编辑测试点（修改所有字段）
   - 删除单个测试点
   - 批量删除测试点
   - 查看测试点详情

2. **列表与筛选测试**
   - 按模块筛选
   - 按优先级筛选（高/中/低）
   - 按创建人筛选
   - 按创建时间范围筛选
   - 按关键词搜索
   - 组合筛选条件
   - 分页验证（翻页、调整每页条数）
   - 空结果验证

3. **关联功能测试**
   - 从测试点生成用例（单条/批量）
   - 查看测试点关联的用例列表
   - 验证用例与测试点的关联关系正确建立
   - 统计卡片数据准确性
   - 点击统计卡片筛选功能

4. **权限测试**
   - 无权限用户访问（应提示）
   - 有权限用户正常操作
   - 只读权限用户无法编辑/删除

---

### 所需资源清单

| 资源 | 说明 |
|------|------|
| 测试账号 | 不同权限级别的账号 |
| 测试数据 | 足够的测试点和测试用例 |
| 测试环境 | 独立的测试环境数据库 |

---

### 预期成果标准（可量化）

- [ ] 所有测试场景执行完成
- [ ] 功能测试通过：≥95%用例通过
- [ ] 无阻塞性bug发现
- [ ] 测试报告输出：记录所有执行的测试用例和结果

## T5.3: 性能测试（列表加载、筛选响应）

| 属性 | 内容 |
|------|------|
| **优先级** | 🟡 中 |
| **负责人** | 全栈开发 |
| **预计工时** | 0.5 小时 |
| **依赖关系** | T5.2 |
| **时间节点** | Phase5 第3个任务 |

---

### 目标描述

验证系统在一定数据量下的性能表现。

---

### 具体测试场景

1. **列表加载性能**
   - 准备500+条测试点数据
   - 测试首次加载时间（目标：<2秒）
   - 测试分页翻页时间（目标：<500ms）

2. **筛选响应性能**
   - 测试单个筛选条件响应（目标：<300ms）
   - 测试组合筛选条件响应（目标：<500ms）
   - 测试关键词搜索响应（目标：<500ms）

3. **批量操作性能**
   - 测试批量删除10条（目标：<1秒）
   - 测试批量生成用例（目标：按需，但不阻塞UI）

---

### 预期成果标准（可量化）

- [ ] 列表加载时间 < 2秒
- [ ] 筛选响应时间 < 500ms
- [ ] 无明显卡顿或延迟
- [ ] 性能测试报告输出
