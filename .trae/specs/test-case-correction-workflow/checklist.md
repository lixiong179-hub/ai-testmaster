# 测试用例纠正功能 - Verification Checklist

## 智能失败分析验证
- [ ] 智能失败原因分析API正常工作
- [ ] 分析API返回问题类型和置信度
- [ ] 测试执行页面显示失败原因分析
- [ ] 测试执行页面显示AI建议的问题类型
- [ ] 用户可以手动切换问题类型判断

## 用例问题场景验证
- [ ] AI建议是用例问题时，显示"纠正用例"按钮
- [ ] 用例问题场景下，不显示任何警告
- [ ] 点击"纠正用例"正确跳转到用例详情页
- [ ] 跳转时正确传递失败步骤ID、失败原因、AI分析等参数
- [ ] 详情页自动切换到技术视图
- [ ] 详情页自动高亮/定位到失败的步骤
- [ ] 详情页显示失败原因和AI分析
- [ ] 用例状态正确设置为"纠正中"

## Bug问题场景验证
- [ ] AI建议是Bug问题时，不显示"纠正用例"按钮
- [ ] Bug问题场景下，显示强烈警告提示"这是Bug问题，不要修改用例！"
- [ ] Bug问题场景下，所有编辑按钮禁用或隐藏
- [ ] Bug问题场景下，技术视图表格不可编辑
- [ ] Bug问题场景下，"快速验证"按钮隐藏
- [ ] Bug问题不会错误地进入用例纠正流程
- [ ] 任何环节都不会默认建议用例纠正（当明确是Bug问题时）

## 后端模型和API验证
- [ ] TestCase 模型有 correction_status 字段
- [ ] TestCaseVersion 模型正确创建并关联 TestCase
- [ ] 用例版本列表API返回正确数据（分页）
- [ ] 版本对比API返回两个版本的差异
- [ ] 版本回滚API正确恢复数据
- [ ] 用例编辑时自动创建版本记录
- [ ] 纠正状态更新API正常工作
- [ ] 状态流转验证生效（不能随意跳转状态）
- [ ] 技术视图步骤定位信息更新API正常
- [ ] 快速添加定位API正常工作
- [ ] 快速验证任务创建API正常工作
- [ ] 快速验证支持选择特定步骤执行

## 前端技术视图编辑验证
- [ ] 技术视图表格有编辑图标或支持双击编辑
- [ ] 双击单元格进入编辑模式
- [ ] 编辑模式支持修改：操作、预期结果、CSS选择器、XPath、AI坐标
- [ ] 编辑时有保存和取消按钮
- [ ] 保存操作正确调用API并更新数据
- [ ] 取消操作正确恢复原状
- [ ] 编辑体验流畅，响应及时
- [ ] Bug问题场景下编辑功能完全禁用

## 前端智能建议面板验证
- [ ] 有失败执行记录时显示智能建议面板
- [ ] 面板显示失败原因（来自执行结果）
- [ ] 面板显示AI分析建议（来自test_result.ai_analysis）
- [ ] 面板显示执行前后的截图对比（如果有）
- [ ] 面板支持折叠/展开
- [ ] 没有失败记录时不显示面板

## 前端快速验证功能验证
- [ ] 技术视图页面显示"快速验证"按钮
- [ ] 点击"快速验证"弹出验证对话框
- [ ] 验证对话框显示步骤列表，支持多选
- [ ] 默认选择所有步骤或只选择修改过的步骤
- [ ] 确认后正确调用快速验证API
- [ ] 调用成功后正确跳转到执行页面
- [ ] 验证对话框可以正常取消
- [ ] Bug问题场景下"快速验证"按钮隐藏

## 前端版本历史功能验证
- [ ] 技术视图页面显示"版本历史"按钮
- [ ] 点击"版本历史"显示版本历史对话框/侧边栏

- [ ] 支持选择两个版本进行对比

- [ ] 确认后正确调用回滚API并刷新页面

## 前端快速添加定位验证
- [ ] 缺少定位的步骤显示"添加定位"按钮
- [ ] 点击"添加定位"弹出定位添加对话框
- [ ] 对话框支持添加：CSS选择器、XPath、AI坐标
- [ ] 提供常用选择器模板或建议（可选）
- [ ] 确认后正确调用API并更新数据
- [ ] 添加成功后刷新显示

## 纠正工作流状态验证
- [ ] 用例执行失败后状态正确更新
- [ ] 进入纠正后状态正确更新为"纠正中"

- [ ] 所有功能协同工作，没有冲突

- [ ] 失败类型判断有明确的视觉标识，避免混淆
- [ ] Bug问题场景下的警告提示足够强烈
- [ ] GetDiagnostics 无 TypeScript/ESLint 错误
- [ ] 项目可以正常启动
- [ ] 响应时间符合要求（主要操作 < 2秒）
- [ ] 代码质量符合项目规范
- [ ] 用户体验良好
