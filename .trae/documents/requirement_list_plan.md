# 需求列表功能优化 - 实现计划

## [ ] 任务 1: 修改后端文件列表API，添加全量文件列表接口
- **优先级**: P0
- **依赖项**: 无
- **描述**:
  - 在 `app/api/v1/endpoints/file.py` 中添加一个新的接口，用于获取所有项目的文件列表
  - 新接口路径为 `/api/v1/file/list`，不包含项目ID参数
  - 接口返回所有用户有权限访问的项目的文件列表
- **成功标准**:
  - 新接口能够返回所有项目的文件列表
  - 接口返回的数据结构与现有接口一致
- **测试要求**:
  - `programmatic` TR-1.1: 访问 `/api/v1/file/list` 接口返回状态码 200
  - `programmatic` TR-1.2: 接口返回的数据包含 `items` 和 `total` 字段
  - `human-judgement` TR-1.3: 接口返回的数据包含所有项目的文件

## [ ] 任务 2: 修改前端文件API模块，添加获取全量文件列表的方法
- **优先级**: P0
- **依赖项**: 任务 1
- **描述**:
  - 在 `src/api/file.ts` 中添加一个新的方法 `getAllFiles`，用于调用全量文件列表接口
  - 方法返回类型与现有 `getFileList` 方法一致
- **成功标准**:
  - 新方法能够正确调用后端的全量文件列表接口
  - 方法返回的数据结构与现有方法一致
- **测试要求**:
  - `programmatic` TR-2.1: 调用 `getAllFiles` 方法能够返回数据
  - `human-judgement` TR-2.2: 方法返回的数据包含所有项目的文件

## [ ] 任务 3: 修改需求列表页面，默认加载全量文件列表
- **优先级**: P0
- **依赖项**: 任务 2
- **描述**:
  - 修改 `src/views/requirement/index.vue` 中的 `getFiles` 函数，默认调用全量文件列表接口
  - 当用户选择具体项目并点击查询时，调用指定项目的文件列表接口
- **成功标准**:
  - 页面加载时默认展示所有项目的文件列表
  - 选择项目并点击查询后，展示该项目的文件列表
- **测试要求**:

  - `programmatic` TR-3.2: 选择项目并点击查询后调用指定项目的文件列表接口
