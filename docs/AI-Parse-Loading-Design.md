# AI 解析加载动画设计方案

## 一、动画设计流程

### 1.1 触发条件
- 用户点击"文本模型一键解析"或"AI视觉解析"按钮
- 调用 `/api/v1/ui-prototype/parse` 接口开始解析

### 1.2 展示时机
- 解析请求发送后立即显示加载动画
- 模态框居中显示，带半透明遮罩层
- 阻止页面其他交互

### 1.3 持续时长
- 动态显示，直至所有屏幕解析完成
- 显示已用时间计时
- 支持中途取消（可选）

### 1.4 结束状态
- 解析成功：显示成功动画，延迟 1.5 秒后关闭
- 解析失败：显示失败状态，保留错误信息
- 用户取消：确认后关闭，回滚状态

- **现代感**：采用渐变色、圆角卡片、流畅动画
- **一致性**：与 Element Plus 组件库风格统一
- **科技感**：AI 主题的电路、脉冲、旋转动画

### 2.2 配色方案
```css
主色调：
- 主蓝色：#409eff (Element Plus 主色)
- 渐变蓝：#409eff → #66b1ff → #8cc5ff
- 成功绿：#67c23a → #95d475

背景色：
- 遮罩：rgba(0, 0, 0, 0.5) + backdrop blur
- 卡片：#ffffff
- 进度条背景：#f0f2f5
```

## 三、交互反馈机制

### 3.1 进度指示
#### 3.1.1 进度条
- 动态渐变进度条
- 带光泽扫描动画
- 实时显示百分比

#### 3.1.2 步骤指示器
```
步骤 1 → 步骤 2 → 步骤 3 → 步骤 4 → 步骤 5
[✓]    [◎]    [○]    [○]    [○]
已完成  进行中  待处理  待处理  待处理
```

**步骤定义：**
| 步骤 | 标题 | 描述 | 进度范围 |
|------|------|------|----------|
| 1 | 初始化解析引擎 | 加载 OCR/视觉识别模块 | 0-15% |
| 2 | 读取并处理图片 | 预处理图像数据 | 15-35% |
| 3 | OCR/视觉识别 | 提取内容和位置 | 35-65% |
| 4 | AI 智能解析 | DeepSeek 分析 | 65-90% |
| 5 | 保存解析结果 | 结构化存储 | 90-100% |

### 3.2 状态提示文字
- **当前步骤标题**：大号字体，醒目显示
- **步骤描述**：小号字体，补充说明
- **实时数据**：
  - 解析模式（文本/视觉）
  - 处理进度（已处理/总数）
  - 已用时间（分:秒）

### 3.3 小贴士轮换
- 每 5 秒轮换一条提示
- 帮助用户了解功能
- 缓解等待焦虑

## 四、性能优化

### 4.1 动画性能策略
- **CSS 动画优先**：使用 `transform` 和 `opacity`，触发 GPU 加速
- **避免重绘**：动画元素独立分层
- **requestAnimationFrame**：JavaScript 驱动动画使用 RAF

### 4.2 具体优化
```css
/* ✅ 使用 transform 和 opacity，GPU 加速 */
@keyframes pulse {
  0%, 100% {
    opacity: 0.4;
    transform: scale(1);
  }
  50% {
    opacity: 1;
    transform: scale(1.05);
  }
}

/* ❌ 避免使用 width/height/top/left，触发重绘 */
```

### 4.3 主线程保护
- 动画独立运行，不阻塞业务逻辑
- 定时器使用 `setInterval` 但间隔合理（500ms）
- 组件卸载时清理定时器

## 六、技术实现

### 6.1 组件结构
```
src/components/loading/
└── AIParseLoading.vue  # 主组件
```

### 6.2 组件 Props
```typescript
interface Props {
  visible: boolean;              // 是否显示
  parseMode?: 'text' | 'vision'; // 解析模式
  totalCount?: number;           // 总屏幕数
  processedCount?: number;       // 已处理数
  showCancelButton?: boolean;    // 显示取消按钮
}
```

### 6.3 组件 Events
```typescript
interface Emits {
  cancel: [];  // 用户点击取消
  close: [];   // 关闭动画
}
```

### 6.4 使用示例
```vue
<template>
  <AIParseLoading
    :visible="parsing"
    :parse-mode="parseMode"
    :total-count="totalScreens"
    :processed-count="processedScreens"
    :show-cancel-button="true"
    @cancel="handleCancelParse"
  />
</template>
```
